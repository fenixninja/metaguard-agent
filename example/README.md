# MetaGuard Agent - Example Playground

This folder contains a minimal, runnable Express server demonstrating the MetaGuard agent integration.

## Quickstart

1. Install dependencies at the repository root:
   ```bash
   npm install
   npm run build
   ```

2. Configure your Meta API key (optional for local testing, required for live LLM responses):
   ```bash
   export META_MODEL_API_KEY="your_meta_model_api_key_here"
   ```

3. Start the demo server:
   ```bash
   npm run example
   ```

4. Open your browser at:
   ```
   http://localhost:3000
   ```
