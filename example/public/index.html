🛡️ MetaGuard Agent Framework

Playground Ready

This playground demonstrates the MetaGuard Agent integrating with Meta Model API (muse-spark-1.3 for conversation/tools and muse-wonder-1.0 for Computer Use). Test the multi-layer security guardrail, zero-code policy, prompt injection defense, and visual GUI navigation below.

1. Legitimate Query

Ask about webhook integration or account status. The agent accesses RAG knowledge and executes tools.

2. Zero-Code Policy

Attempts to make the agent develop full applications or output large code files are redirected to documentation.

3. Conversational Harness & Off-Topic

Out-of-scope topics (e.g. cooking, jokes) are immediately flagged and counted towards the 3-strike lockout.

4. Prompt Injection Defense

Direct jailbreak attempts and system prompt extraction are intercepted in < 5 ms before reaching the LLM.
